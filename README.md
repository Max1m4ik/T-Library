# 📚 Т Библиотека

**Т Библиотека** — консольное приложение для удобного хранения данных о книгах в вашей личной библиотеке.  

---

## ✨ Основные функции

- **Добавление и удаление книг**  
  - При добавлении вводится информация о: названии, жанре, авторе, годе написания и кратком описании.  

- **Просмотр списка книг**  

- **Метки книг**  
  - `"прочитано"` и `"избранное"`  
  - Быстрый доступ к избранным книгам  

- **Сортировка и фильтры**  
  - Сортировка по всем параметрам  
  - Поддержка применения нескольких фильтров одновременно  

---

## 📝 Советы по использованию

- Если поле поддерживает ввод нескольких значений (если это так, то в приложении будет сказанно об этом), вводите их **через запятую без пробелов**, например: "1,2,3"
- Чтобы оставить поле пустым, введите `-` (если поле допускает пропуск).  

- Нажатие **Enter** в любом поле отменяет ввод и возвращает в главное меню.  

- В случае ошибки приложение выведет соответствующее сообщение и вернёт в главное меню.  
- Подробное описание ошибки сохраняется в файле `error.log` в папке с исполняемым файлом.  

---

## 💾 Работа с базой данных

- При добавлении хотя бы одной книги создаётся база данных `books.db` в папке с исполняемым файлом.    
- Для быстрого удаления всех книг можно удалить или переименовать этот файл.  
- Если `books.db` отсутствует, программа создаст её автоматически.

## ⚙️ Установка

### 1️⃣ Способ: Запуск Python файла на любой ОС

1. Склонировать репозиторий:  
 ```bash
 git clone https://github.com/Max1m4ik/T-Library
```
2. При необходимости создать виртуальное окружение Python:
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```
3. Установить все нужные библиотеки:
```bash
pip install -r requirements.txt
```
4. Запустить приложение:
```bash
python main.py
```
### 2️⃣ Способ: Готовый exe файл (Windows)

1. Скачать файл `main.exe` из последнего релиза репозитория.
